# 마우스 올려두기 번역 — Windows

## 간단한 사전 설명

단축키를 매번 누르지 않아도 글자 위에 마우스를 약 1초 멈추면 주변 사각형을 한 번 번역합니다. 기존 고정 영역 자동 번역과 한 번 실행하는 마우스 단축키는 유지합니다.

## 자세한 설명

### 사용 순서

1. 기존 OCR 언어·번역 언어·개인 API 키·전송 동의를 설정합니다.
2. **마우스 올려두기 번역** 체크 또는 **Ctrl+Alt+H**로 켭니다. H가 점유돼 있으면 F9를 시도하며 실제 단축키가 체크 상자 옆에 표시됩니다. 모두 등록하지 못하면 체크 상자를 사용합니다.
3. 번역할 글자 위에서 약 1초 멈춥니다. 범위는 좁게 360×100 / 보통 640×160 / 넓게 960×240 논리 픽셀입니다.
4. 결과는 주변 캡처 아래(공간이 부족하면 위)에 표시합니다. 화면 자막 옵션이 꺼져 있으면 기존 결과 창을 사용합니다.
5. 다른 위치로 옮긴 뒤 멈추면 다시 읽습니다. 같은 위치에서 문자가 바뀌어도 상시 반복 캡처하지는 않습니다. 그런 사용에는 Ctrl+Alt+P의 고정 영역 자동 번역을 사용합니다.
6. 같은 켜기·끄기 키, 체크 해제, 또는 처리 중 취소 버튼으로 끕니다. 새 실행에서는 항상 꺼져 있습니다.

### 상태·비용·구현 경계

- 150ms마다 포인터 위치와 버튼 상태만 확인하고, 정지 시간이 1000ms를 넘으면 한 번 캡처합니다. 실제 실행 시점은 폴링 간격과 UI 스케줄링만큼 늦을 수 있습니다.
- 기준 위치에서 맨해튼 거리 12 논리 픽셀 이내의 작은 흔들림은 기다리는 시간을 다시 시작하지 않습니다.
- 마우스 버튼을 누르고 있거나 드래그 중이면 읽지 않습니다. Windows GetAsyncKeyState의 현재 상태 비트로 다른 앱이 입력을 받는 동안의 버튼도 확인합니다.
- 이 앱의 메인/결과 창이 캡처 범위를 가리거나 포인터가 번역 자막 위에 있으면 읽지 않습니다. 설정·파일 선택 등 대화 상자 중에는 대기합니다.
- 요청 중 다른 위치로 이동하면 이전 작업을 취소하고 오래된 결과를 버립니다. 이미 전송한 번역 요청 비용은 취소되지 않을 수 있습니다. 실행 중인 OCR 계산도 즉시 중단되는 것은 아닙니다.
- 고정 영역 자동 번역과 상호 배타적입니다. 한 번 번역·이미지 가져오기·영역 선택·재시도 같은 명시적 작업으로 전환할 때도 올려두기 모드를 끕니다.
- OCR 원문만 기존 설정에 따라 번역 서비스로 전송합니다. 개발자 공용 키·중계 서버·새 네트워크 서비스를 추가하지 않았습니다. 같은 OCR 원문의 최근 번역 재사용도 그대로입니다.
- 구현은 Windows MainWindow 어댑터에만 추가했습니다. C++ 공통 코어와 모바일 코드는 변경하지 않았습니다.

### 검증 방식

- 테스트에서는 포인터 좌표·경과 시간을 직접 공급해 1초 대기, 작은 흔들림, 같은 위치의 중복 억제, 이동·끄기 시 취소, 드래그와 자체 창 회피를 확인합니다.
- 실제 화면에 일본어 테스트 창을 띄워 주변을 캡처하고 실제 PaddleOCR로 읽습니다. 네트워크 키를 비운 테스트이므로 OCR 성공을 번역 성공으로 표시하지 않습니다.
- 고정 영역 자동 번역과의 상호 전환, 저장 영역 유지, 새 실행에서 꺼짐, 네이티브 단축키 메시지 처리를 확인합니다.
- 신규 세 테스트는 초기화·정리를 포함하여 5개 통과했습니다. 기존 앱 종료 후 최종 CTest 7개 그룹 전부 통과했고, Windows UI 검증은 22개 통과했습니다. 설치본 실행 종료 코드 0과 배포본/설치본 SHA-256 일치도 확인했습니다. [최종 검증 기록](evidence/windows-hover-checks.json).
- [UI 화면](evidence/windows-hover-ui.png). 실제 사용자의 게임별 인식 품질·물리 키보드 입력·혼합 배율 다중 모니터는 이 테스트만으로 확인한 것으로 보지 않습니다.
