# 편의성 검토와 보완 — 계획과 결과

작성·완료 2026-11-23 · 백로그 P-41 · 브랜치 `ocr-accuracy-foreign-only` · 기준 커밋 `4b1114d`

요청: "프로젝트 편의성 검토 이후 편의성 부분 보완 계획 세우고 개발 진행. 개발 파트 끝나도 다른 부분 계속 개선하며 개발."

## 1. 검토 방법

- 설치부터 첫 번역까지를 README대로 따라가며 사용자 입장에서 읽었다.
- 새 도구 `tests/ui_shots.cpp`(테스트 아님)로 앱의 모든 창을 찍었다: 메인 창 3가지 상태(처음 실행, 준비됨, 자막 표시 중), 설정 8쪽, 대사 기록, 결과 창, 자막 미리보기. 테스트용 설정으로 띄워 사용자의 설정과 키는 읽지도 바꾸지도 않는다. 결과는 작업 폴더에만 두고 저장소에 넣지 않는다.
- 설치본 메인 창도 한 장 찍었다(`--smoke-test --screenshot`).

## 5. 이어서 고친 것

계획의 개발을 마친 뒤, 어두운 모드와 메뉴, 설치본(사용자 설정 그대로) 화면을 더 찍어 보고 고쳤다.

| 무엇 | 본 것 | 바꾼 것 | 확인 |
|---|---|---|---|
| 어두운 모드 | `ui_shots --dark`(Qt 6.8의 색 구성 전환)로 14장 + 메뉴 2장. 메인 창·설정·기록·결과 창 모두 색이 따라간다 | — | 화면 확인 |
| 메뉴의 단축키 | 트레이 메뉴는 자동 번역·올려두기·자막 숨기기에만 단축키가 보이고 영역 선택·지금 번역에는 없었다. ⋯ 메뉴의 자막 숨기기에도 없었다 | 단축키가 있는 메뉴 항목은 모두 실제 쓰는 키를 보인다 | `nextStepAndKeyHintsFollowTheState`에 확인 추가 |
