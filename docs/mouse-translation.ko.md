# 마우스 주변 번역 — Windows

## 간단한 사전 설명

글자 위에 마우스를 놓고 단축키를 누르면 주변을 한 번 캡처하여 기존 비동기 OCR → 번역 → 화면 자막 흐름으로 처리합니다. 저장한 게임 자막 영역은 덮어쓰지 않습니다.

## 자세한 설명

### 사용법

1. 원문 언어와 번역 언어를 고릅니다. 번역에는 기존 설정의 사용자 개인 DeepL 키와 전송 동의가 필요합니다.
2. 메인 창에서 범위를 고릅니다: 360×100 / 640×160(기본) / 960×240 논리 픽셀.
3. 앱을 최소화하고 글자 위에서 **Ctrl+Alt+M**. 충돌하면 **Ctrl+Alt+F8**로 자동 대체하며 메인 창의 실제 단축키를 따릅니다. 이 PC는 M이 이미 사용 중(Windows 오류 1409)이어서 F8을 등록했습니다.
4. 단축키를 쓰기 어려우면 **마우스 번역 · 3초 준비**를 누른 뒤 글자로 마우스를 옮깁니다. 취소 버튼으로 대기와 처리를 중단할 수 있습니다.
5. 결과는 캡처 영역 아래, 공간이 부족하면 위에 표시됩니다. 화면 자막을 끄면 기존 결과 창을 사용합니다. 자동 번역 재개는 **Ctrl+Alt+P**입니다.

### 구현 경계와 상태

- Windows 어댑터만 변경했습니다. 공통 코어에는 Qt, 마우스 좌표, 모니터, 단축키를 넣지 않았습니다.
- `QCursor::pos()`로 단축키 처리 시점의 전역 좌표를 읽고, `screenAt()`으로 해당 모니터를 찾습니다. 같은 모니터 안에서 캡처 사각형을 이동·축소하며 화면 경계 밖은 읽지 않습니다.
- 캡처 좌표는 Qt 논리 픽셀입니다. 실제 이미지 픽셀 크기는 모니터 배율을 따릅니다. 캡처 직전 모니터 제거·해상도·배율 변경을 다시 검사합니다.
- 기존 `Capture::region → processImage(ST_SCREEN_CAPTURE)`를 재사용합니다. 캡처 전 앱 창과 자막을 잠시 숨겨 자체 글자가 OCR에 들어가지 않게 합니다.
- 요청별 자막 위치와 마지막 이미지의 자막 위치를 따로 보관합니다. 재시도와 저장 영역 미리보기가 서로의 위치를 덮어쓰지 않습니다.
- 마우스 번역은 고정 영역 자동 번역을 멈춥니다. 새 마우스 요청은 미완료 요청을 취소하고, 세대 번호로 오래된 완료 알림을 무시합니다.
- 취소는 결과 반영을 막습니다. 실행 중인 PaddleOCR 계산이 즉시 중단되는 것은 아니며, 이미 전송한 번역 요청 비용도 되돌리지 않습니다.
- 키·언어·동의 저장소와 기존 텍스트 중복 처리를 재사용합니다. 이미지와 번역 내역을 새로 저장하거나 공용 API 키를 추가하지 않았습니다.

### 검증 결과 (2026-09-29)

Windows 11, MSVC 2022, Qt 6.8.3, ONNX Runtime 1.30.0에서 Release 빌드 및 CTest 6개 그룹을 통과했습니다. Windows UI 검증은 초기화·정리를 포함하여 18개 통과, 건너뛴 항목은 없습니다.

- 실제 Windows 단축키 등록 + `WM_HOTKEY` 메시지 전달 → 자체 일본어 테스트 창의 마우스 주변 캡처 → 실제 PaddleOCR로 `天気` 인식.
- 단축키 이후 마우스를 옮겨도 캡처 위치와 재시도 위치가 유지됨.
- 저장한 게임 영역·설정 유지, 고정 영역 자동 번역 중지, 범위 설정 복원, 잘못된 저장 크기의 기본값 복구.
- 게임 영역을 선택하지 않은 상태에서도 마우스 캡처 시작 가능. 캡처 전 취소와 3초 대기 취소 후에는 이미지나 늦은 결과가 나오지 않음.
- 음수 모니터 좌표·화면 모서리·작은 화면·잘못된 좌표는 계산 테스트로 확인.
- 키 없는 경로는 OCR 원문만 표시하며 실제 번역 성공으로 표시하지 않음.
- 설치본 `--smoke-test` 실행 종료 코드 0, [실행 화면](evidence/windows-mouse-ui.png)으로 UI 확인.

이번 변경에서는 외부 번역 API를 새로 호출하지 않았습니다. 기존 실제 연결 검증은 README에 구분되어 있고, 이번 번역 프로토콜 검증은 로컬 테스트 서버를 사용했습니다. 실제 키보드의 물리 입력, 실제 게임별 전체화면 호환성, 복수 모니터/서로 다른 배율 조합은 별도 사용자 테스트가 필요합니다. Android/iOS에는 마우스 기능을 구현하거나 테스트하지 않았습니다.

증거: [검증 요약](evidence/windows-mouse-checks.json), [UI 테스트](evidence/windows-mouse-windows-flow.txt), [캡처·OCR 테스트](evidence/windows-mouse-local_checks.txt).

### 제한

단어 위치를 탐지하는 모델은 추가하지 않았습니다. 포인터 주변 사각형 안의 글자를 읽기 때문에 배경·다른 문장이 함께 들어오거나 문장 끝이 잘릴 수 있습니다. 범위를 조절하거나 기존 자막 영역 선택을 사용하세요. 보호된 화면이나 보안 데스크톱의 캡처 제한을 우회하지 않습니다.
